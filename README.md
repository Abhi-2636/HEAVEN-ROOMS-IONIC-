## ✨ About the Project

**Heaven Rooms** is a modern, mobile-first student accommodation platform built with **Ionic + TypeScript**.  
It helps students near **LPU** explore rooms, compare pricing, and contact easily for bookings.

---

## 🚀 Features

- 🏠 Browse room listings with details & images  
- 💰 View pricing & amenities clearly  
- 📱 Fully responsive (mobile-first design)  
- ⚡ Fast & smooth performance  
- 📞 Quick contact / inquiry system  
- 🎯 Clean and intuitive UI
